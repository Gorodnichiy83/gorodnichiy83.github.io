# Павел Городничий

Персональная визитка руководителя проектов обучения.

Сайт: https://gorodnichiy83.github.io/

## Как обновлять сайт и резюме

1. Откройте `index.html` на GitHub и нажмите карандаш **Edit this file**.
2. Измените нужный текст, сохраняя HTML-теги вокруг него. Здесь редактируются кейсы, опыт работы, образование, курсы и контакты.
3. Нажмите **Commit changes** и сохраните изменения в ветке `main`.
4. В разделе **Actions** дождитесь зелёной отметки у **Publish website and PDF**. Обычно сборка занимает несколько минут.
5. Откройте [сайт](https://gorodnichiy83.github.io/) и скачайте резюме кнопкой **Скачать резюме PDF**.

`index.html` — единственный источник содержания. GitHub автоматически создаёт из него печатную страницу `resume.html` и PDF: сначала кейсы с бизнес-результатами, затем опыт, подход и образование. Вручную менять `resume.html` или загружать PDF после каждой правки не нужно: при следующей сборке они будут созданы заново из `index.html`.

Отдельный файл адресной книги `pavel-gorodnichiy.vcf` для кнопки **Сохранить контакт** пока редактируется вручную, если меняется телефон или почта.

Обновление работает на GitHub, даже когда компьютер выключен. Сайт и резюме публикуются вместе после успешной проверки. Если сборка красная, прежняя опубликованная версия остаётся доступной; откройте неудачную сборку и её шаг с ошибкой. Ссылки на PDF получают новую версию, чтобы браузер не показывал ранее скачанный файл из кэша.

Файлы `resume.html` и `pavel-gorodnichiy-resume.pdf` в списке репозитория — сохранённые копии на момент настройки. Актуальная автоматически собранная версия доступна по кнопкам на опубликованном сайте.

## Локальная сборка

Нужен Python 3.12. Зависимости используются только при сборке; сайт остаётся статическим.

```sh
python -m pip install -r requirements-resume.txt
python -m unittest -v test_resume_sync.py
python build_site.py
python -m http.server 8765 --directory _site
```

Результат сохраняется в `_site/`. Генератор `build_resume.py` извлекает содержание из существующих классов и секций HTML. Обычные текстовые правки и добавление записей в существующие списки поддерживаются; при изменении структуры или имён классов потребуется обновить генератор.

## Публикация

GitHub Pages: **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/publish.yml` запускается при каждом сохранении в `main`; его также можно запустить через **Actions → Publish website and PDF → Run workflow**. Он собирает проверенный `_site/` и публикует его целиком, без дополнительных токенов и без записи сгенерированных файлов в репозиторий.

Лицензия шрифта Onest находится в `OFL.txt`.
